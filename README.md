# 🎓 Neurofocus. - Perfil de Aprendizagem

O **Aprende.** é uma aplicação web interativa projetada para ajudar estudantes a descobrirem seu estilo predominante de aprendizagem: **Visual, Auditivo ou Cinestésico**. Através de um quiz rápido e intuitivo, o usuário recebe um diagnóstico personalizado e dicas práticas de estudo.

![Tecnologias](https://img.shields.io/badge/Tecnologias-HTML--CSS--JS-blue)

## 🚀 Funcionalidades

- **Sistema de Autenticação:** Login e Cadastro com validação de dados e segurança (hashing de senha local).
- **Interface Responsiva:** Design moderno "Dark Mode" com suporte para dispositivos móveis.
- **Quiz Dinâmico:** Questionário interativo com barra de progresso em tempo real.
- **Diagnóstico Personalizado:** Resultado baseado nas respostas do usuário com ícones e cores específicas para cada perfil.
- **Dicas de Estudo:** Sugestões práticas (Mapas Mentais, Podcasts, Projetos Reais, etc.) baseadas no perfil identificado.
- **Persistência de Dados:** Uso de `LocalStorage` para manter usuários e sessões salvos no navegador.

## 🛠️ Tecnologias Utilizadas

*   **HTML5:** Estrutura semântica dos componentes.
*   **CSS3:** Estilização avançada com variáveis, animações `keyframes` e Glassmorphism.
*   **JavaScript (Vanilla):** Lógica de banco de dados local, roteamento de telas e cálculo do perfil.
*   **Google Fonts:** Fontes 'Playfair Display' e 'DM Sans'.
